# ParamorphicConcept Unit

Schematic address: `ontology-core/ontology-knowledge-unit/paramorphic-concept-unit` · Type: Unit · State: placeholder · 0% completed to goal

The OKU's unit holding the **paramorphic concepts** (owner's ruling, 2026-11-19: all paramorphic concepts are in a ParamorphicConcept Unit in the OKU). A paramorphic concept is a generic abstract structure whose form is a family generated by a declared parameter set — one concept, moved along its parameters, yields its variants while keeping its identity. The theory comes from the owner's paramorphic-components framework, where the same concepts are components (Grid the most developed; Graph, Tree, Path, Protocol and Logic envisioned there, and named here as this unit's contents).

## Contents — closed at six (owner's ruling, 2026-11-19)

- **Grid** — cells as host, occupants placed on them. AnSci instances: the Luoshu (the QuantificationUnit's apparatus); the classical filing tables.
- **Graph** — nodes and labelled edges, the kernel the relational concepts stand on. Instances: the correspondence graph, the meaning graph, the connective graph, the Variant Graph, the ProblemSolving approach graphs.
- **Tree** — a rooted graph under the parent constraint. Instances: the WordNet hypernym climb, the schematic / system tree, the classical filing schemes, the Slice A–C class and category stops. The owner's motivating case, a code AST, has no specimen in this system yet.
- **Path** — both readings the components record reconciles: points and segments as a substrate, and an ordered record of a traversal. AnSci's specimens are all the second: `mapPath`, the climb path, the derivation path, the Luoshu flight path.
- **Protocol** — framed message streams; turn-taking as its native order. **No specimen in this system** — a located gap, recorded in the registry rather than filled; the nearest banked material (the Social Unit's turn-taking bar, the turn loop) is not filed as an instance, because neither was built as a Protocol.
- **Logic** — triples over the Graph kernel, with typing and inference. Instances in effect, never before named as Logic: the classification table read as triples; the generating and controlling cycles as inference rules.

Network is not a seventh concept — it folds into Graph (topology) and Protocol (transport), as the components record ruled; Timeline and Spatial Structures were named there but never developed. Adding a concept is the owner's ruling, not a registration.

## The unit's relation to instances (owner's ruling, 2026-11-19)

The unit holds the generic concepts, their parameters and their shared operations. The system's existing structures are **instances and stay where they live** — the correspondence graph beside this unit in the OKU, the meaning graph in the parser's work, the Luoshu inside the QuantificationUnit. Nothing is moved by this placement, and nothing is re-expressed in the unit's terms. A future engine slice, if commissioned, would serve the instances where they stand.

## The standing invariant

Carried over from paramorphic theory's one earlier entry into this system (`docs/design-conversation-engine.md` § Morphs: an invariant core never morphs): **moving a concept along a parameter may generate a derived candidate; it may never rewrite a filed row in the classification table or the correspondence graph, and never upgrade a provenance tier.** Attestation does not morph. Registered per concept in the registry, alongside the concept-specific brakes (the Tree entry carries the X1 brake: no unpriced automatic inheritance).
