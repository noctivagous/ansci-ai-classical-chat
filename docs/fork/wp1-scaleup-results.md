# The 500-object run — primary classifications (test subset, 400)

Commissioned 2026-11-15. Sample: `wp1-scaleup-sample.md` (frozen
before this run; classifications deliberately not pre-filled).
Calibration subset: the pilot's 100 objects in
`wp1-pilot-results.md`, whose assertion-layer record stands and
whose second occurrences in this sample are the R8 consistency
check. Protocol: Part E §E.5–E.6 — the five-tier ladder (T1
attested · T2 established correspondence · T3 registered-heuristic
inference · T4 novel prediction · T5 unresolved); the pilot's
R1–R8 as split by §E.6; H5/H6/H7 as registered; P1/P2/P6/P7 as
registered in §E.6.

**Sealed ordering (Part E §E.5).** These primary classifications
are committed to file *before* any blind output is opened. The
blind reproducibility subsample is run only after this file is
complete, and its output is compared against what is written
here, unedited.

**Method.** Axes: material and nature as separate assertions;
function recorded in words and assigned an element for none
(phase-null by protocol, every tier). Every non-T5 position names
its tier and its rule. Grades from the pilot carry over: T1 =
attested (pilot grade A); T2 = attested correspondence (B-direct);
T3 = derived under a registered rule or a ratified pilot ruling
(H5/H6/H7 outputs, B-derived bridges, stuff-class and
single-material calls — the pilot's B-derived and C calls, the
procedure for which the pilot validated); T4 = a §E.6 prediction
rule (P1/P2/P6/P7) applied beyond its validated range; T5 = no
registered rule reaches the position. Component assertions count
within their object's position, as in the pilot. **Nothing in
this document is banked into `classify.ts`** — as with the pilot,
banking is a separate, separately approved pass.

Notation: `Element · tier · confidence · rule`; `— T5` =
unresolved (a scored outcome). Where two traditional forms of an
artefact diverge in material, the traditional constitutive form
is asserted and flagged *type-dependent*, following the pilot's
rope precedent; where two forms are equipollent, the position is
T5 with both readings recorded.
