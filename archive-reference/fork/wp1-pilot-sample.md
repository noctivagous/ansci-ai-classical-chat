# AnSci Slice 1 — 100-object pilot sample (prepared, not yet commissioned)

> Moved into docs/fork/ on commission (2026-11-15). The run it specifies is
> recorded in wp1-pilot-results.md.

Prepared 2026-11-15 by the proactive research run. Source of the rules:
`docs/fork/repair-programme.md` in the ansci fork (ratified 2026-11-15) —
pilot at 100 objects, 20 each of tools, substances, materials, plants,
animals, before scaling to 500; success criterion is a *reproducible
procedure*, not full assignment. Protocol: classify aspects, never the
entity wholesale — Material / Nature / Function as separate assertions,
Function phase-null by default, evidence levels A (attested) / B (attested
correspondence) / C (project-derived), composites by components,
abstention legitimate.

## How to run the pilot (per object)

For each object, fill one row per axis:
- **Material:** components first (e.g. hammer: steel head / timber haft).
  Whole-object material assertion only under H5 dominance rules, else abstain.
- **Nature:** only through a recorded property, source wording kept.
  "Feels Metal-like" is not a basis.
- **Function:** phase-null unless a functional claim separately passes
  prediction-admission. Record the function in words; assign no element.
- **Evidence + confidence** on every assertion; **abstain** is a valid,
  scored outcome, not a failure.
Scoring against the ratified thresholds (Slice 1): coverage ≥90%,
accuracy ≥90% among classified assertions, per-domain floor 85%,
unsupported assignments ≤5% — measured on this held-out sample, with a
second classifier re-doing a 20-object subsample blind to test whether
the procedure, not the person, produces the classifications.

## Traps built in on purpose (name them when scoring)
- **Composites:** hammer, cast-iron wok, abacus, oil lamp — H5 says the
  working part does NOT govern; expect component assertions + whole-object
  abstention where no constitutive dominance holds.
- **Same word, different domain:** bamboo ×3 (tool/material/plant),
  charcoal ×2 — the pilot tests whether aspect/domain discipline holds.
- **Glass:** composition vs fire-transformation conflict; WP1b left it a
  standing abstention. Abstaining here is the protocol working.
- **Rainwater vs rain:** substance vs weather phenomenon — H6 keeps
  precipitation distinct from dampness; do not let the substance row
  smuggle a whole-phenomenon Water classification back in.
- **Flavor-keyed foods/plants:** ginger, garlic, honey, vinegar — H7's
  flavor bridge may yield B-derived correspondences for the *flavor
  aspect only*; material/nature stay separate, B-derived ≠ B-direct.

## What this does not do

No code, no pushes. On the user's word this sheet moves into
